# EduLearn – Engineering & Technology Career Portal

EduLearn is a modern **Engineering & Technology Career Portal** built using React.js. It helps students, freshers, and graduates explore career paths, job roles, skills, and career preparation opportunities based on their educational background and interests.

## 🚀 About the Project

The platform provides career guidance for students from different educational backgrounds such as:

* CSE / IT
* AI & Machine Learning
* Data
* ECE
* EEE
* Mechanical
* Civil
* Chemical
* Aerospace
* Robotics
* MPC / Mathematics & Science

Users can explore suitable career domains, understand job roles, discover important technologies, and access career preparation resources.

* Modern and responsive UI

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/nandinibandi/EduLearn.git
```

Navigate to the project:

```bash
cd EduLearn
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

## 📋 Project Functionality

The project is completely **frontend-only**.

The Career Guidance / Callback form uses React `useState` for handling the form interaction.

When the user clicks the career assistance button:

```text
User clicks button
        ↓
Success modal opens
        ↓
Success message displayed
        ↓
User clicks Close
        ↓
Modal closes
```

No backend or database is required.
